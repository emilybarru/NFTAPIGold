# NFTAPIGold

NFTAPIGold enables real-time, decentralized NFT data processing through a scalable, load-balanced gateway platform.

NFTAPIGold is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTAPIGold.git`
2. `cd NFTAPIGold`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
